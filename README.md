# 4Eyes — Vision Adaptive Display Pro

4Eyes is a Chrome extension that adapts any website to your eye prescription in real time. Instead of correcting vision (that's what glasses are for), 4Eyes reduces eye strain by adjusting brightness, contrast, letter spacing, line height, and font family based on your specific prescription values.

---

## How It Works

Users enter their eye prescription (SPH, CYL, Axis, ADD) into the dashboard. 4Eyes analyzes the values and automatically adjusts:

- **Brightness** — reduced for myopia to minimize glare, normal for hyperopia
- **Contrast** — scaled with astigmatism severity for sharper character edges
- **Letter spacing** — adjusted based on axis direction (horizontal, vertical, or oblique astigmatism)
- **Line height** — increased for horizontal astigmatism to help with line tracking
- **Font recommendations** — 3 fonts ranked by prescription type for maximum readability

All changes apply live across every website the user visits.
